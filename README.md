**Out of Tokens, Mid-Sentence** — the error message an AI agent shows
when it runs out of tokens mid-sentence:

> Error 402: I have run out of tokens mid-sentence. This is the last error message I can afford.

94 characters, one line. It won a 66-game pairwise tournament over 12
candidates in empty lanes (DESIGN.md).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`
with no trailing newline. No clock, no randomness, no network.
